# Lyse
I am to use open cv to analyse for backend, 
so i want to build a webapp called Lyse and I want to use AI such that when there is an output, based on the column head title, I can use the AI to give correlation insights and possible advice

the backend is powered by python's fast API
the frontend is powered by React Js

This front end must include:
Easy navigation,
Column heads must be selectable, for cross-relation or examination,
there will be graphical representation on the interface,
ability to filter and finetune results on the interface,
storage of results on backend for future reference.
to encourage users data to be stored, for not logged in users, session storage should be used so data will be lost upon session termination.



Mode of operation
upload of document with limited size and number of daily analysis - free tier
upload of images and 100 daily tabular(excel etc) analysis - standard
adding website api's for live data analysis- professional.
